# Doppely

Асимметричная многопользовательская трёхмерная игра: 4–8 игроков пытаются выявить нейросеть-доппельгангера, которая притворяется одним из них.

## Стек

- **Платформа:** Windows
- **Язык:** Rust
- **Движок:** Bevy
- **Сеть:** lightyear
- **Обучение нейросети:** dfdx
- **UI:** React через `bevy-react` (`ui/`)

## Сюжет

Действие происходит на Базе по исследованию природы аномалии-доппельгангера. Аномалию поймали и отправили в лабораторию для изучения, но однажды она выбирается из капсулы и забирается в костюм, пытаясь подражать игрокам.

## Игровое время

- Игра длится **7 раундов (дней)**, каждый день — **12 минут**.
- За это время нужно выполнить все задачи либо покрыть задачами необходимую квоту. За каждое отклонение от квоты вся лаборатория получает штраф.
- За неделю сотрудники должны создать сыворотку для уничтожения доппельгангера.
- Сам доппельгангер выбирается из капсулы в один из первых дней (**1, 2 или 3**) и пытается сбежать, мимикрируя под игроков.

## Доппельгангер и сотрудники

- Доппельгангер ломает объекты на базе. В этих объектах хранятся данные по его уничтожению, поэтому игроки выполняют задания и проводят исследования, а доппельгангер им мешает.
- Костюмы меняются каждый день, у каждого свой номер. Номер можно записать на своё наручное устройство.
- У сотрудника при себе всегда есть «Руководство сотрудника».

## Текущее состояние

Реализовано:

- клиент-сервер на lightyear с предсказанием и интерполяцией, движение игрока (WASD, Shift, мышь);
- клиент видит режим сервера: лобби, игра или редактирование;
- редактор сцены: сервер с `--editing`, клиент подключается и строит сцену — свободная камера, спавн, выбор и перетаскивание мышью, мультивыбор, поворот и масштаб, отмена и повтор правок, сохранение и загрузка сцен;
- меню со списком серверов: онлайн и число игроков на каждом (отдельный статус-порт `port + 1`);
- лобби до 8 игроков: любой участник запускает игру, в игре новые подключения отклоняются;
- режимы сервера: лобби, игра, редактирование (переключение из консоли сервера);
- UI на React: меню, лобби, редактор, HUD, пауза, экраны подключения и ошибок.

В планах: раунды и задачи, объекты с данными, сыворотка, костюмы и наручные устройства, поведение доппельгангера.

## Редактор сцены

Для этого нужно запустить сервер с флагом `--editing` (и опционально `--scene <имя>` — сразу загрузит сцену).

Управление в режиме редактирования:

| Действие | Управление |
|---|---|
| Полёт камеры | `W` `A` `S` `D`, вверх — `Space`, вниз — `Ctrl` |
| Обзор | удерживать правую кнопку мыши |
| Меню создания | `F` — список примитивов в точке под курсором |
| Выбрать / перетащить | левый клик по объекту, тянуть — двигать по полу |
| Мультивыбор | `Shift` (или `Ctrl`) + клик по объекту или строке в инспекторе |
| Снять выбор | левый клик по пустому месту |
| Удалить выбранные | `Delete` или кнопка в инспекторе |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Y` (или `Ctrl+Shift+Z`) |

Создаваемые объекты — примитивы (по набору коллайдеров avian): куб, сфера, капсула, цилиндр, конус. Цвет материала и свечение зависят от типа объекта.

Отдельный тип — **точка спавна** игроков: у неё нет ни меша, ни коллайдера, в мире (лобби и игре) она не отображается вообще, а в режиме редактирования видна как маленькая полупрозрачная сфера, чтобы её можно было выбрать и перетащить.

Справа — **инспектор сцены**: список объектов (ID, имя, координаты) и свойства выбранного. Клик по строке или по объекту в сцене выбирает его (выбранные объекты подсвечиваются), `Shift+клик` добавляет или убирает объект из выбора; последний выбранный — «основной», его свойства показываются в инспекторе сущности.

В инспекторе сущности три группы полей: **позиция**, **поворот** (в градусах, по осям XYZ) и **масштаб**. Каждое значение можно тянуть зажатой ЛКМ по букве-метке (влево/вправо, как в Unity/Blender) или вводить вручную; изменения сразу уходят на сервер.

Ниже — **инспектор компонентов** основного объекта: `dynamic`, `glow`, `light` (`intensity`, `radius`), `friction` (`coefficient`). Компоненты добавляются кнопками `+ …` и удаляются крестиком; изменение применяется на сервере сразу (объект пересоздаётся с новым набором компонентов). Набор компонентов хранится в сцене, поэтому переживает `save`/`load`.

При старте игры сервер расставляет игроков по точкам спавна по кругу (позиция игрока = позиция точки). Если в сцене нет ни одной точки, в лог пишется ошибка, а игроки появляются в позиции по умолчанию.

Сцены лежат в `assets/scenes/<имя>.json`. Сохранение и загрузка выполняются на сервере, клиент получает результат (успех/ошибку) через репликацию. Те же действия доступны из консоли сервера: `spawn`, `room`, `remove`, `save`, `load`, `scenes`, `undo`, `redo`.

## Отмена правок

История правок хранится на сервере: перед каждым изменением сцены (спавн, перемещение, поворот, масштаб, удаление, набор компонентов, загрузка сцены) снимается снимок всей сцены. `Ctrl+Z` откатывает последний снимок, `Ctrl+Y` возвращает его обратно. Непрерывные изменения (перетаскивание, вращение числа ЛКМ) склеиваются в один шаг истории, если идут чаще 0.7 с. Глубина истории — 64 шага; при сохранении сцены история не сбрасывается, но и в файл не попадает.

## Компиляция и запуск

### Сервер

```ps
cargo run --release --bin server --features server
```

Режим редактирования сцены (стартует в состоянии `Edit` и принимает команды построения):

```ps
cargo run --release --bin server --features server -- --editing
```

Загрузить сохранённую сцену из `assets/scenes` (без флага — пустой мир с одним кубом):

```ps
cargo run --release --bin server --features server -- --scene my_room
```

### Обучение нейросети на видеокарте с CUDA-ядрами

```ps
cargo run --release --bin server --features server,cuda
```

### Клиент

```ps
cargo run --release --bin client --features client
```

## UI

Интерфейс клиента — React-приложение в `ui/`, которое рисуется силами `bevy-react`.
Перед первым запуском клиента его нужно собрать:

```ps
cd ui
npm install
npm run build
```

Клиент загружает `ui/dist/app.js` и `ui/dist/vendor.js` относительно рабочего каталога,
поэтому `cargo run` надо выполнять из корня проекта.

Для разработки UI удобен watch-режим (клиент подхватывает изменения без перезапуска):

```ps
cd ui
npm run watch
```

Типизированный мост React → Rust (`ui/src/bevy.ts`) генерируется из Rust:

```ps
cargo run --features client --bin client -- --export-bindings ui/src/bevy.ts
```

## Конфигурация

- `assets/config.json` — адрес и порт локального сервера, адрес прослушивания (`bind`), пароль сети и `protocolId`. Отсутствующие поля берутся по умолчанию; порт статуса — `port + 1`.
- `assets/servers.json` — список серверов в меню (Localhost вшит в код и всегда первый).
- `assets/scenes/<имя>.json` — именованные сцены: создаются командой `save <имя>` в режиме редактирования и загружаются через `--scene <имя>` или `load <имя>`. Без сцены сервер начинает с пустого мира, в котором лежит один куб.

## Особенности запуска

- `client --connect 127.0.0.1` — пропустить меню и сразу подключиться (удобно для отладки).
- Консольные команды сервера: `players`, `debug`, `lobby`, `game`, `edit`, `help`, `exit`.
- Команды сцены:

  ```
  list                                   — объекты сцены
  spawn box|sphere|capsule|cylinder|cone|crate <x> <y> <z> [размеры]
  room <x> <z> [ширина глубина] [высота] — пол и четыре стены
  remove <id>|all
  scenes                                 — сохранённые сцены
  save <имя> / load <имя>                — assets/scenes/<имя>.json
  ```
